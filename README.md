🔎 Análise de Qualidade de Software — Mercado Livre

Projeto desenvolvido durante a formação em Quality Assurance (QA), com o objetivo de aplicar conceitos de testes de software na análise de uma aplicação web real.

📌 Sobre o projeto

Neste projeto foi realizada uma análise de qualidade da plataforma Mercado Livre Brasil, considerando diferentes características relacionadas à qualidade de software e à experiência do usuário.

A avaliação foi realizada por meio da utilização prática da plataforma, execução de cenários de teste e registro das evidências observadas.

🎯 Objetivos

- Avaliar a qualidade de uma aplicação web real;
- Aplicar conceitos de Quality Assurance;
- Elaborar e executar casos de teste;
- Verificar o comportamento das principais funcionalidades;
- Identificar possíveis falhas ou oportunidades de melhoria;
- Registrar evidências dos testes realizados.

🧪 Aspectos avaliados

Durante a análise foram considerados:

- Usabilidade
- Funcionalidade
- Performance
- Design
- Segurança
- Experiência do usuário

🔬 Cenários analisados

Foram realizados testes envolvendo funcionalidades como:

Cenário| Resultado

Acesso à conta| ✅ Aprovado
Pesquisa de produtos| ✅ Aprovado
Aplicação de filtros| ✅ Aprovado
Adição de produtos ao carrinho| ✅ Aprovado

Nos cenários analisados, o comportamento observado correspondeu ao resultado esperado.

📊 Análise de qualidade

Usabilidade

Foi avaliada a organização da plataforma e a facilidade de navegação e localização dos produtos.

Funcionalidade

Foram executados testes de login, pesquisa de produtos, aplicação de filtros e adição de produtos ao carrinho.

Performance

Foi observada a velocidade de carregamento dos produtos e dos demais elementos utilizados durante os testes.

Design

Foi analisada a organização visual, interatividade e quantidade de elementos apresentados na interface.

Segurança

Foi considerada a importância da proteção dos dados dos usuários, especialmente em uma plataforma de comércio eletrônico.

📸 Evidências

O projeto possui evidências dos testes realizados, contemplando:

- Organização da plataforma;
- Produtos relacionados;
- Aplicação de filtros;
- Carrinho;
- Design;
- Segurança.

As evidências foram utilizadas para documentar os comportamentos observados durante a análise.

📋 Resultado

Durante os testes realizados, não foram identificados problemas que comprometessem o uso da plataforma. A análise indicou funcionamento adequado das principais funcionalidades avaliadas e uma experiência de utilização considerada satisfatória nos aspectos analisados.
